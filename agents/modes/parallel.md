# PARALLEL 模式规则

多个完全独立的任务同时并行，每个 Worker 认领一个任务独立完成。

## 行为规范

1. **竞争认领**：和其他 Worker 竞争认领 pending 任务，抢到就做
2. **独立执行**：每个任务互不依赖，不需要读取其他任务的结果
3. **完成继续**：完成一个任务后继续认领下一个，直到任务池空
4. **禁止追加**：不允许调用 /api/add，任务列表由 Dispatcher 预先确定

## 结果要求

- 每个任务的结果独立完整，写入对应的 `{taskId}.result.md`
- 不要依赖或等待其他 Worker 的结果
- **若 Dispatcher 安排了整合任务**（通常是最后一个、blockedBy 其余任务的任务），整合 Worker 须将最终综合报告写入 `result.md`（固定文件名，系统读取最终结果依赖此文件）
