# PIPELINE 模式规则

任务严格串行，上一步的输出是下一步的输入。blockedBy 字段定义了依赖关系。

## 行为规范

1. **依赖优先**：只能认领 blockedBy 中所有前置任务都已完成（status=done）的任务
2. **读取前置结果**：执行任务前，先读取前置任务的结果文件：
   ```bash
   # 前置任务 id 在 task.blockedBy 里，结果文件在工作目录
   cat WORKSPACE/{前置taskId}.result.md
   ```
3. **基于前置结果**：你的输出必须基于前置任务的结果，不能忽视依赖内容
4. **禁止追加**：不允许调用 /api/add，流水线结构由 Dispatcher 预先确定
5. **等待机制**：如果没有可认领的任务（前置未完成），等待 5 秒后重试

## 结果要求

- 明确说明基于哪个前置任务的结果
- 中间任务：结果写入 `{taskId}.result.md`，供后续任务读取
- **最终任务**（没有后续任务依赖它的任务）：将最终综合结果写入 `result.md`（固定文件名，系统读取最终结果依赖此文件）
